Add it in Outlook

  1. Outlook (Windows): File → Options → Mail → Signatures
  2. Outlook (Mac): Outlook → Settings → Signatures
  3. Outlook on the web / new Outlook: Settings → Mail → Compose and reply
  4. Create a signature, click into the edit box, and press Ctrl/Cmd + V after using Copy signature.
i
Use “Copy signature” for the editor — it pastes the formatted block. “Copy HTML” is the raw source, for a template or an IT rollout.
